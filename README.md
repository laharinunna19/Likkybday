# 💜 Advance Happy Birthday — Likky Vadhina 🎂

A simple, elegant and aesthetic **birthday countdown website** created specially for my best friend, **Likky Vadhina**. 🌷✨

The website counts down to **October 18, 2026 — 12:00 AM** and reveals a special birthday message when the countdown reaches zero. 🎉

---

## ✨ Features

* 🎂 Birthday countdown
* 💜 Lavender aesthetic theme
* 🌷 Soft pastel design
* ✨ Floating hearts and animations
* 💌 Friendship quotes
* 📱 Mobile responsive design
* 💻 Desktop friendly
* 🎉 Automatic birthday reveal
* ❤️ No external images required
* ⚡ Pure HTML, CSS & JavaScript

## 🎂 Birthday Countdown

The countdown is set for:

**October 18, 2026 — 12:00 AM**

Before the birthday:

```text
DAYS : HOURS : MINUTES : SECONDS
```

When the countdown reaches zero, it automatically changes to:

```text
🎂 HAPPY BIRTHDAY, LIKKY VADHINA! 💜
```

## 🌐 GitHub Pages Deployment

This project can also be hosted using **GitHub Pages**.

1. Upload all project files to a GitHub repository.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Choose the main branch.
6. Select the root folder.
7. Save the settings.
8. GitHub will generate a live website link.
